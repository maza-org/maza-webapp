# MAZA Store Submission Assets

This folder contains the draft store assets for MAZA `4.4.6`.

## Icons

- `icons/app-store-icon-1024.png` - 1024 x 1024 PNG, no alpha.
- `icons/play-store-icon-512.png` - 512 x 512 PNG, no alpha.
- `icons/play-adaptive-foreground-432.png` - adaptive icon foreground source.

## Screenshots

- `screenshots/app-store-6.7/` - 1290 x 2796 screenshots for App Store 6.7-inch display uploads.
- `screenshots/play-phone/` - 1080 x 2340 screenshots for Google Play phone uploads.
- `screenshots/raw/` - original 430 x 932 browser captures.
- `screenshots/contact-sheet.png` - quick visual QA sheet.

Screenshots were captured from the local Expo web build using seeded demo data, then exported to store-safe PNG dimensions.

## Console Text And Answers

- `store-listing.md` - Play Store and App Store listing copy.
- `privacy-data-safety.md` - Google Play Data safety and Apple App Privacy draft answers.
- `reviewer-access.md` - reviewer access and demo account instructions.
- `release-signing-versioning.md` - signing/versioning notes and EAS commands.

Before submission, replace placeholder support/contact values with the live public privacy policy URL and monitored support email.
